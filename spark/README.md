# Spark для учебных продаж

Spark выполняет Python-программы через PySpark. Один локальный Docker-стек
содержит master, worker и клиент для запуска программ. Автоматической
генерации или записи продаж при старте контейнеров нет.

## Запуск

В корне проекта:

```bash
docker compose up -d --build
```

Если остальные сервисы уже работают, можно запустить только Spark
и его необходимые зависимости:

```bash
docker compose up -d --build spark-master spark-worker spark-client
```

Первая сборка скачивает образ Spark и PostgreSQL JDBC-драйвер.
Суммарный предел памяти трёх контейнеров Spark: 4,5 ГБ, дополнительно
к остальному стеку. Это лимит, а не постоянный расход памяти.

- http://localhost:8082: master, список worker и приложений.
- http://localhost:8083: worker, выполняемые задания.
- http://localhost:4040: подробности приложения, только пока оно работает.

Порты можно изменить через SPARK_MASTER_UI_PORT, SPARK_WORKER_UI_PORT
и SPARK_APP_UI_PORT в .env. Без новых переменных используются эти значения.

## Файлы

- Dockerfile: Spark 3.5.8, Java 17, Python и PostgreSQL JDBC 42.7.8.
- conf/spark-defaults.conf: адрес master, настройки памяти, связи процессов.
- jobs/: твои будущие Python-скрипты, доступны в контейнере /opt/spark/jobs.

Первый учебный файл предстоит написать: jobs/scale_sales.py.
Он пока не создан, чтобы реализовать преобразования по шагам вместе.
После его создания запуск будет таким:

```bash
docker compose exec spark-client /opt/spark/bin/spark-submit /opt/spark/jobs/scale_sales.py
```

Python-драйвер запускается в spark-client, вычисления выполняются на worker.
Запускай одно приложение за раз: адрес и порты драйвера фиксированы.
Файлы jobs подключены только на чтение; результаты нужно писать в PostgreSQL,
а не поверх исходных скриптов.

## Подключение к данным

Реквизиты уже передаются в spark-client через переменные окружения:
DWH_POSTGRES_HOST, DWH_POSTGRES_PORT, DWH_POSTGRES_DB,
DWH_POSTGRES_USER и DWH_POSTGRES_PASSWORD. Читать их нужно в Python,
не записывать пароль в код и не печатать его.

В сети Docker адрес PostgreSQL: dwh-postgres:5432.
Порт 5433 используется на компьютере, а не между контейнерами.
JDBC-драйвер org.postgresql.Driver включён в образ всех трёх сервисов.
Он позволяет Spark читать и записывать PostgreSQL через JDBC.

## План первого задания

1. Создать SparkSession и прочитать raw.kaggle_coffee и raw.cities через JDBC.
2. Создать вариант каждой исходной продажи для каждого города.
3. Присвоить воспроизводимые ID, одну позицию чека и количество 1.
4. Задать условные рублёвые цены на основе исходных чисел. Это учебные
   цены, не подтверждённая валюта Kaggle и не валютная конвертация.
5. Добавить небольшие воспроизводимые отклонения между городами.
6. Определить местное время городов и преобразовать его в момент продажи.
7. Проверить результат перед записью. Сохранить исходный Kaggle нетронутым.
8. Подготовить отдельные таблицы учебных чеков и позиций с защитой от дублей.

Для условных продаж сохраняем происхождение и признак синтетических данных.
Коэффициенты цен, часовые пояса и механизм повторной записи ещё предстоит
выбрать и реализовать. Конфигурация Spark сама эти правила не выполняет.
